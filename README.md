# Crypto V3.5 Institutional Scanner

A selective alert-only crypto scanner designed for GitHub Actions and Telegram.

## Features

- BTC 4H market-regime filter
- Coin 4H and 1H trend alignment
- 15m Break of Structure
- Change of Character
- Liquidity sweep detection
- Fair Value Gap reaction
- Order Block reaction
- Support/resistance proximity filter
- EMA, RSI, ADX, ATR and volume confirmation
- Confidence score from 0–100
- ATR/structure-based stop loss
- TP1, TP2 and TP3
- Telegram chart image
- Duplicate alert suppression
- Persistent signal-state and performance files

## GitHub secrets

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

## Important

This bot is alert-only. It does not place orders. SMC concepts are algorithmic approximations and may not match discretionary chart interpretation. Forward-test before risking capital.
